# Power BI · ES / EN

Extraer el ZIP completo y abrir el archivo .pbip en Power BI Desktop. Pulsar Actualizar para cargar el snapshot CSV incorporado; no requiere rutas locales, credenciales ni licencia de publicación. Seleccionar Resumen ES u Overview EN.

Extract the entire ZIP and open the .pbip file in Power BI Desktop. Select Refresh to load the embedded CSV snapshot; no local data paths, credentials or publishing subscription required. Select the ES or EN page.

Los datos incorporados son un snapshot: editar un CSV externo no actualiza el modelo. Para un nuevo período, regenerar primero los agregados y después el modelo. Las tablas muestran granos distintos y no tienen relaciones artificiales entre sí.

Embedded data is a snapshot: editing an external CSV does not update the model. Rebuild aggregates and the model for a new period. Tables have different grains and no artificial relationships.
